# Cloud Coding Agents

A retro-styled pixel art website showcasing the cloud coding agents of "The Agentic Era" (2026). Built with Astro.js featuring a dark purple theme with neon accents and nostalgic 8-bit aesthetics.

## 🎮 Live Preview

Visit the website to explore comprehensive information about 9 major cloud coding agents across three categories:
- **The Autonomous Giants**: Devin, Factory.ai, OpenHands
- **The Ecosystem Natives**: Jules, GitHub Copilot Workspace, GitLab Duo, AWS Kiro
- **The Interactive Powerhouses**: Cursor 2.0, Replit Agent

## ✨ Features

- 🎨 **Dark Purple Retro Design** - Pixel-perfect borders with neon glow effects
- 🔤 **Pixel Art Font** - Press Start 2P from Google Fonts
- ⚡ **Animated Elements** - Glowing text, floating backgrounds, scanline effects
- 🃏 **Interactive Cards** - Agent cards with hover effects and pixel box styling
- 📊 **Comparison Table** - Feature matrix with star ratings
- 📱 **Responsive Design** - Optimized for all screen sizes
- 🎯 **Custom Favicon** - Pixel art icon design

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🛠️ Tech Stack

- **Framework**: Astro.js 4.x
- **Language**: TypeScript (strict mode)
- **Styling**: Pure CSS with custom properties
- **Font**: Press Start 2P (Google Fonts)
- **Build Tool**: Vite
